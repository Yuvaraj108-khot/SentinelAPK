# SentinelAPK

SentinelAPK is an AI-powered APK analysis platform developed for cybersecurity and banking fraud detection.

It analyzes Android applications using a multi-stage pipeline:

- Static APK inspection
- Permission and manifest analysis
- LLM-powered intent reasoning
- UI impersonation detection
- Runtime behavior assessment
- Unified risk scoring
- Explainable investigation reports

The goal is to help analysts identify malicious banking apps, phishing APKs, OTP stealers, and credential harvesting malware faster than traditional signature-based approaches.
